# DeepBrief UX/UI Case Study

This package is ready for GitHub Pages.

## Publish

1. Create a public GitHub repository named `deepbrief`.
2. Upload the contents of this folder to the repository root. Upload the files and folders, not the ZIP itself.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. The site will be available at `https://YOUR-USERNAME.github.io/deepbrief/`.

All website assets use relative paths and work on GitHub Pages. Each video is kept below GitHub's browser upload limit.
